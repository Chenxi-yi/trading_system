# 项目章程 v0.1

## 使命

建立可运行、可审计、可恢复、可迭代的个人系统化投资能力。
寻找经济逻辑成立、样本外稳定、成本后仍存在的期望收益；负面研究结果也是有效产出。
“机构级”指研究纪律、风险约束和运营控制，不是软件规模或盈利标签。

## 决策关系

PM 决定投资范围、资金与风险预算、阶段晋级及实盘启动。
研究/开发提出假设、实现、证据和反例。风险规则具有拒绝权。
一个人兼任多个角色时，也必须保留研究审查、风险审查和上线审查的不同记录。
AI 复核不能称作真正独立的验证团队。

## 投资边界

2026-10-20 用户明确：目标运行场所 OKX，范围为现货、合约、美股；准备提供模拟盘 API。
Crypto 研究从 BTC/ETH/SOL 开始；Daily 传统趋势优先，4H 是后续独立研究。
用户已确认 OKX Global，美股范围为股票永续与 x-stock 现货；模拟账户产品可用性待测（ADR-0002）。
第一版建议以无借贷现货 long/flat 建立账本和因果基线；
这是一项建议，产品范围尚待 PM 决定。永续模型必须包括历史 funding、保证金和强平。
暂不做 HFT、大规模 ML 搜索、复杂跨所套利或未经审计的自动资金移动。

## 证据要求

- 每个想法先写：谁可能为收益付费？为什么存在？何时应失效？有什么可反驳预测？
- 收益必须与预先选定的基准、风险和成本一起解释，不能用胜率或 Sharpe 代替全部证据。
- 不默认回测 PnL 是 alpha。区分 beta、风险溢价、市场择时、杠杆、流动性补偿和残差收益。
- 研究失败、试验次数、人工选择、成本变更都保留。
- 不因看见留出集结果而悄悄修改假设、区间、基准或阈值。
- 新复杂模型必须证明对简单 baseline 的样本外净增益与运维价值。

## 阶段交付格式

能力 → 证据 → 已知缺陷 → PM 决策 → 下一步与理由。
实盘晋级取决于统计、经济、执行和运营证据；任何单一统计阈值都不是上线许可。
