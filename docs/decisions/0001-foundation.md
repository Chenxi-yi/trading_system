# ADR-0001：模块化单体与研究审计优先

日期：2026-10-20
状态：v0.1 工作基线；投资与实盘预算未批准。

背景：空白项目，希望长期可持续研究并最终个人实盘，先设计架构而非立刻建全套交易系统。

决策：

- 使用模块化单体和明确边界；实际实现从最小端到端链路扩展。
- 先 Daily 可解释趋势；4H、额外 crypto 数据和 ML 后续研究。
- 以 Git + 状态文件 + ADR + 实验 manifest 保持连续性。
- Risk、成本、时间因果、账本自第一条回测开始，不是事后附加。
- 当前仅创建文档和教学算例；不提前接真实账户。

替代：微服务、云集群、大规模模型搜索、直接套成品回测最优参数。
拒绝理由：现阶段没有需求证据，增加维护成本或隐藏研究自由度。

代价：早期仍可能修改接口；未来多场所、反向合约、并发运行可能要求迁移存储和调度。
不承诺“架构一次设计好，今后只需改策略”。

重新评估触发：真实数据暴露时间/产品语义缺口；并发运行瓶颈；订单恢复需求；
新增资产类；多个策略组合的归因无法保持一致。
