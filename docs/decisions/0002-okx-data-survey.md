# ADR-0002：OKX 目标场所与数据源分层

日期：2026-10-20。状态：场所与范围来自用户指示；数据接入方案仍待讨论。
补充 ADR-0001，不改变研究验证和实盘授权规则。

用户确定：Bot 在 OKX 上运行，标的范围现货、合约、美股；将提供模拟盘 API。
允许调研其他交易所公开行情。先交付可视化数据源地图，再讨论填入数据模块。

本轮：

- 官方文档核查与少量无签名 GET；不安装 Kit、不接私有账户、不下单。
- OKX 原生行情作为目标产品事实来源；外所和美股数据提供参考，不静默替换执行市场价格。
- 用户后续明确账户为 Global，美股范围为股票永续与 x-stock 现货；传统股票仅作为参考数据。
- 美股区分 equity / tokenized-equity spot / equity perpetual，不能共享同一 ticker 身份。
- 实测公共市场存在 AAPL-USDT-SWAP、XAAPL-USDT；这不证明用户可交易或模拟盘支持。
- Agent Trade Kit 是可选交互/操作工具；网格 demo 限制已记录，风控不能交给工具代替。

待讨论：第一批数据与历史范围、供应商预算；待测试：Global 模拟账户的具体产品权限。
完整数据契约和架构修改应在讨论之后实施。
