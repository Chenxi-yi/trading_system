# ADR-0007：前台连续推进，调度仅负责恢复

2026-10-21。PM明确指出“有空闲资源为什么不跑”，要求现在继续。

取代ADR-0006中的每日最多2批及以4小时触发为主要推进节奏；它们是Agent自行设置的资源政策，非验证门槛。
不改任何冻结实验、成本、参数或判定门槛；只修正工作调度。

- 资源可用、有新机制/数据/工程任务时，前台顺序继续，不在批次之间等下一个时钟。
- 每批最多8alpha+4对照、三批方法审计、跨批累计与最终未知样本规则保留。
- 恢复heartbeat改为每15分钟，单次恢复最多1批；有活动进程时不重复写入，优先补不冲突的工作。
- 未触发后台/未运行进程时如实说未在计算；ACTIVE调度状态不能当作正在回测。
- 额度不足或真正缺外部数据才保存等待，不动用购买/重置额度或新增付费。
- 没有新机制不穷举参数；可推进公开观测、执行保护/恢复和真实前瞻基础。
- 本地调度条件不变；只有实际观测到的数据才有first-observed可得时刻，不回填PnL。
