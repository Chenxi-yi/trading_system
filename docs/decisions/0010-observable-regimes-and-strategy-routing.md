# ADR-0010：可观测市场状态与策略路由

PM于2026-10-21恢复研究并指定市场阶段/策略适配方向。状态识别与策略有效性是两个不同待检验命题。先固定当时可得特征与确认规则，再归因和路由；不用未来涨跌命名阶段，不把HMM全样本平滑状态用于交易。先简单价格/波动规则，不搜索状态数/特征/分界以追收益。

029旧收益条件归因，不改变旧交易。030统一真实资金账本重放切换，计调仓与退出成本；固定专家/固定混合/只做波动控制为对照。主规则与敏感性在029结果前共同登记，不按状态收益表选赢家。网格库存/撤单/突破亏损需独立模型，不用日收益直接拼接。

新研究评价增量与不确定性，不把每年盈利当理论必要条件；旧研究门槛和失败不改。已访问历史仍为适应性探索，复杂选择器不能恢复未知样本。状态误判、确认延迟、切换成本与尾部作为结果，必要时现金。固定前瞻OI研究独立，模型/终点不变。无订单/付费授权。
