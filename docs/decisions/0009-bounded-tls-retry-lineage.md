# ADR-0009：为实际TLS EOF另建有界重试采集来源

012真实捕获一次SSLEOFError/errno8。只能确认错误类型，不能断言服务端、代理或本地原因；不关闭证书验证、不换域名绕路。

保留010所有源码、协议、数据/失败/快照，不删除或更换其fingerprint。013另设数据根目录、协议、源快照及manifest。导入前先锁定并独立复核父353日/raw，复制原始body和下载metadata、父checkpoint；不重写原始接收时间，质量缺口和旧失败继续保留。新版本继承父retry_after_epoch，不提前试探相同源。

只对SSLEOFError允许最多2次重试，分别等2秒和5秒，每次实际HTTP尝试（失败也算）计入每段100GET。其他错误仍按原规则停止/退避；403/451停止且无自动绕过，完整性错误停止。重试不会增加预算，不用付费/账户API。三次同类失败后保留600秒退避，不能忙等。

这是数据传输工程修订，不修改旧研究PnL/策略/准入门槛，不产生新OOS或alpha。若故障类型不同，不推广重试白名单。PM已有授权内实施，未改变资金风险或交易权限。
