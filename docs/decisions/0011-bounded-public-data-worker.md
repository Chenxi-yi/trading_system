# ADR-0011：研究计算与公开采样分离

PM已授权持续免费公开观测。长模型研究不能充当精确15min数据时钟，新增有界本机采样组件039/040，只执行既有白名单，不新增API/凭证/订单权限。最长4h/17tick，真实quota gate缓存最多30min/人工暂停/时钟及来源变化/失败均停止。btc仍负责模型恢复和真实额度查询，不能以本组件替代或冒称修复应用唤醒。

039全src动态枚举启动限制在新增无关研究文件后实际拒绝。040保持父runtime不变，使用固定父执行依赖集合及自身哈希；执行依赖改变仍拒绝。老来源不覆盖，040不提高权限。先停止采样再生成一致恢复包，之后重启同冻结版本。实际跨桶和终止/单锁已验，完整寿命/长期连续性未验。
