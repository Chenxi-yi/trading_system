# ADR-0003：USDT 资金边界与多策略记账

日期：2026-10-20。
状态：USDT-only 资金边界来自 PM 明确指示；以下隔离与分配设计待实现及验收。

## 用户决定与预算解释

模拟账户中只使用 USDT 作为策略投入和保证金；原有其他币种不主动出售、转出、借出或用于抵押。
支持未来并行验证多个策略。账户余额多于 Bot 的规划预算不自动扩大资金授权，
继续沿用私有 mandate 的既定总模拟预算；每策略资金分配在这个总预算内确定。
未因这次说明获得即时下单、改账户模式、自动借贷或实盘权限。

## 现货仓位与受保护资产

USDT-only 指资金来源和保证金币种，并不禁止现货策略用 USDT 新买入 BTC、ETH 或 x-stock。
这些新产生的仓位属于 Bot 及对应策略，允许后续按规则卖出；不能动用同币种的预存余额。
在首次交易前建立本机受保护资产数量基线；涉及公司行动/用户手工变更时需对账调整。
报单卖出量不得超出 Bot 自有可用库存，现货费用需计入对应库存；不自动启用旧 OKB 抵扣等旧资产消费路径。
保护不能只依赖虚拟账本：账户保证金模式若会自动计入旧资产，先隔离或停用该路径再启动。
不得把多币种总权益或异常模拟估值作为 Bot 可用资金。

## 并行策略设计

- 每策略独立记录分配本金、可用/冻结资金、订单、库存、净损益、费用、funding 与版本。
- 账户层统一分配与预留资金，避免多个策略同时重复使用同一笔 USDT。
- 单策略目标先合成，再经组合风险与执行；同产品反向信号不得各自独立抢单。
- 合并/净额订单的成交与费用需要预先固定归属规则，保持策略损益合计与 Bot 账本一致。
- 风险同时包含单策略限额、Bot 总预算、underlying 总敞口和 USDT 保证金缓冲。
- Bot 总体亏损基准用既定初始本金，不能拿未分配 USDT 或预存币种收益掩盖 Bot 亏损。
- 虚拟分账不提供交易所层面隔离；单账户共享保证金与强平风险必须单独审查。

## 接下来的验收

W1 核验账户模式、自动借贷和抵押品范围，记录是否能满足 USDT-only。
W3 建立每策略账本、预存库存保护与 Bot/账户对账。
Portfolio/Risk 实现总预算、资金预留与策略分配；未通过不运行多策略交易。
首次运行的产品优先选择账户能力允许、规则清晰且满足该资金约束的 USDT 产品；不改总体研究范围。
