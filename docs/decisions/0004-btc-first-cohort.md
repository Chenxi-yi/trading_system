# ADR-0004：首批围绕 BTC 比较多个策略

日期：2026-10-20。状态：PM 已明确首批聚焦 BTC，并允许网格；具体候选与上线仍需验证。

## 决定

首批比较 BTC 趋势、均值回归、有限现货网格；将 BTC carry 列入候选清单，先完成数据与双腿风险验收。
总体投资范围不改，已有 ETH/SOL 数据保留。先把单标的完整链路做对，减少首批工程和搜索维度。
研究计划：research/plans/BTC_FIRST_COHORT.md；R-0004 网格单独登记，不与 R-0003 混称。

## 约束与后果

首轮各族先一个主要候选；改参数、网格形状/范围、重新锚定、增加状态过滤器都计入试验预算。
网格的已实现小利润与剩余 BTC 浮亏一起进入总 NAV；有限资金/库存，禁止无限加仓或自动扩大预算。
多个 BTC 策略共享 underlying、USDT、OKX 风险，不因名称不同假定分散，组合需核验相关性与压力暴露。
回放并行研究不等于立即并行下单；资金/库存保护、Risk 和 Execution 门槛不变。
当前单账户 USDT-only 与预存资产保护要求继续生效，不按机构报告擅自开多币种抵押。
